# SGLE-Tacna
Prototipo modular en C++ de un Sistema de Gestión de Emergencias para los distritos de Tacna. Proyecto de primer ciclo desarrollado colaborativamente vía Git/GitHub para la Unidad 02 del curso Fundamentos de Programación - UNJBG. Incluye menú interactivo CRUD, estructuras y reportes estadísticos automatizados.
